# NOVA PLAY V2 — Advanced Virtual Coin Demo

Premium dark/neon mobile-first sports and games UI.

### Features
- Rich home dashboard with live feed indicator and stats
- Search teams, players and leagues
- Cricket, Football, Tennis and Basketball
- Live/upcoming odds through The Odds API
- Match details with market tabs
- Favorites
- Virtual bet slip
- Virtual coin wallet
- Login/register
- Bet history
- Game lounge
- Responsive glass-style bottom navigation
- Express 5 + SQLite
- Render ready

### Render
Build: `npm install && npm run build`
Start: `npm start`

Environment:
`JWT_SECRET` and optional `ODDS_API_KEY`

### Safety
Virtual coins only. No cash deposits, UPI/payment processing, cash withdrawals, or real-money wagering.
